# One-input contact checkpoints

The geometry-only [wall reversal fixture](../../fixtures/wall-reversal.json) has carried +X velocity and a finite wall beyond the start/goal supports. It supplies no wall-hit time, contact plane, recorded facing or airtime. The route search generated one X hit on input 0, cancelled normal carry and moved outward on input 1. It finished on the goal after 12 inputs with zero added runs, shared scene acceptance and independently validated scalar constraints. Cold search took about 6.96 seconds locally.

[wall-request.json](wall-request.json) is the compiled request with the found yaw witness; [wall-result.json](wall-result.json) records its trajectory, generated hit and movement metadata. Its yaw is a warm validation witness, not an input to cold discovery. The independent geometry checks use intended movement before clipping. Sprint is cancelled on the following input and the carried air factor changes one input later.

The integration regression also cold-solves X and Z reversals with both signs, and checks that disabling wall hits leaves this declared family unknown. This is not a global infeasibility certificate. Shared scene regressions cover paired X/Z hits, repeated hits, finite misses, a nearer blocking solid and mere boundary arrival.

Current wall generation is a bounded same-side reversal family. The normal half-plane is held during this leg's Y-overlap intervals before and after the hit; rounding the same solid later in that leg is not generated by this first family. Other obstacles retain their independent passage chains and full scene checks. The defaults are two selected wall hits per route and 24 retained wall-hit candidates, in addition to the existing joint contact-branch budget. These configurable limits are separate from the per-block blockage caps. Ladders/vines remain deferred.
